# 13. Словарь

Слова, которые встречаются в коде и в этой книге. Если что-то в тексте
непонятно, скорее всего оно здесь.

## Графика

**Вершина (vertex)** — точка модели вместе с её данными: позиция, нормаль,
координата текстуры. В этом движке 32 байта, см. `struct gfx_vertex`.

**Индекс** — номер вершины. Треугольники задаются тройками индексов, чтобы
не хранить одну и ту же вершину по нескольку раз.

**Меш (mesh)** — массив вершин плюс массив индексов. Одна модель, одна
комната, один предмет.

**Нормаль** — единичный вектор, перпендикулярный поверхности. Нужна для
освещения: чем сильнее она повёрнута к свету, тем ярче точка.

**Координата текстуры (UV)** — точка на картинке, куда попадает вершина. От
0 до 1 по каждой оси; больше единицы значит повтор, если он включён.

**Текстура** — картинка, натянутая на треугольники.

**Атлас** — одна текстура, в которой лежит много маленьких картинок сеткой.
Здесь так хранится шрифт.

**Texel** — пиксель текстуры. Отличают от пикселя экрана, потому что
соответствие между ними не один к одному.

**Мипмапы (mipmaps)** — уменьшенные копии текстуры (1/2, 1/4, 1/8...).
Видеокарта берёт подходящую по расстоянию. Без них далёкая текстура
«кипит». В движке пока нет.

**Шейдер** — программа, выполняемая видеокартой. Вершинный решает, где
вершина на экране; фрагментный — какого цвета пиксель.

**GLSL** — язык шейдеров OpenGL, синтаксически похож на C.

**Фрагмент** — кандидат в пиксели. Становится пикселем, если проходит
проверку глубины и не отброшен `discard`.

**Растеризация** — превращение треугольника в набор фрагментов.

**Uniform** — переменная шейдера, одинаковая для всего вызова отрисовки:
матрица, цвет, направление света.

**Атрибут** — поле вершины, своё у каждой вершины.

**Varying** — значение, которое вершинный шейдер передаёт фрагментному.
Интерполируется по треугольнику. Так работает затенение по Гуро.

**VBO / IBO** — буферы вершин и индексов в видеопамяти.

**Draw call (вызов отрисовки)** — команда «нарисуй вот этот кусок буфера».
Основная единица стоимости: сто вызовов по сто треугольников медленнее
одного вызова на десять тысяч.

**Буфер глубины (z-buffer)** — расстояние до ближайшей нарисованной
поверхности для каждого пикселя. Позволяет рисовать в любом порядке.

**Z-fighting** — мерцание двух поверхностей, лежащих почти в одной
плоскости: точности буфера глубины не хватает решить, какая ближе.

**Отсечение задних граней (backface culling)** — отбрасывание треугольников,
повёрнутых к камере изнанкой. Определяется порядком обхода вершин.

**Обход вершин (winding)** — по часовой или против. Против часовой с точки
зрения камеры считается лицевой стороной.

**Фрустум** — объём, видимый камерой: усечённая пирамида из шести
плоскостей.

**Отбраковка (culling)** — отказ рисовать то, чего не видно.

**Гуро (Gouraud shading)** — освещение считается в вершинах и
интерполируется по треугольнику. Дёшево, выглядит как эпоха PS2.
Противоположность — Фонг, где освещение считается в каждом пикселе.

**Двойная буферизация** — кадр рисуется в невидимый буфер, потом буферы
меняются местами. Без этого видно процесс рисования.

**Спрайт / билборд** — плоская картинка, всегда повёрнутая к камере.

**Ортографическая проекция** — проекция без перспективы, дальнее не
уменьшается. Используется для 2D-интерфейса.

**Матрица MVP** — произведение матриц модели, вида и проекции. Переводит
вершину из системы координат объекта прямо в экранную.

**Column-major** — порядок хранения матрицы по столбцам. Так ждёт OpenGL.

## Мир и столкновения

**AABB** — коробка, грани которой параллельны осям координат. Не
поворачивается, зато все проверки с ней — сравнения чисел.

**Сектор** — комната или её часть: что рисовать и в каких границах.

**Портал** — четырёхугольник, за которым виден другой сектор. Дверной
проём.

**PVS (potentially visible set)** — заранее посчитанная таблица «из какого
места какие места видны». Требует оффлайн-компилятора уровня; в этом
движке заменена порталами в рантайме.

**BSP** — дерево двоичного разбиения пространства. Давало порядок
отрисовки до появления буфера глубины. Здесь не используется, обоснование в
`docs/04-decisions.md`.

**Свип (swept test)** — проверка столкновения не в точке, а вдоль всего
пути движения. Без неё быстрый объект проскакивает сквозь стены.

**Разность Минковского** — приём, превращающий «коробка против коробки в
движении» в «луч против раздутой коробки».

**Скольжение (sliding)** — гашение той части скорости, что направлена в
стену, с сохранением остальной. Благодаря ему игрок не залипает в углах.

**Барицентрические координаты** — способ задать точку внутри треугольника
тремя весами. Их выдаёт алгоритм пересечения луча с треугольником.

## Память

**Арена** — блок памяти, из которого выделяют, двигая указатель вперёд, и
освобождают целиком. См. главу 04.

**Bump allocator** — второе название того же.

**Выравнивание (alignment)** — требование, чтобы адрес был кратен размеру
типа. На некоторых процессорах его нарушение — аварийное завершение.

**LIFO** — «последним пришёл, первым ушёл». Порядок, в котором арена умеет
освобождать.

**Фрагментация** — состояние, когда свободной памяти много, но она разбита
на мелкие куски и большой блок не выделяется. Арене не свойственна.

**Непрозрачный дескриптор (opaque handle)** — число, по которому модуль
находит свои данные. Наружу видно только число.

**POD** — структура из простых полей без указателей. Записывается на диск
одним `write`.

## Звук

**PCM** — несжатая последовательность мгновенных значений громкости.

**Сэмпл** — одно такое значение. **Кадр** — по сэмплу на каждый канал.

**Чередование (interleaved)** — порядок хранения стерео: левый, правый,
левый, правый.

**Частота дискретизации** — сколько сэмплов в секунду. 44100 — стандарт CD.

**Underrun** — буфер устройства опустел раньше, чем игра подала новые
данные. Слышно как щелчок.

**Фиксированная точка 16.16** — способ хранить дробь в целом числе:
верхние 16 бит целая часть, нижние 16 дробная. Используется для пересчёта
частоты без накопления ошибки.

**Constant power panning** — панорама с корнями, при которой суммарная
мощность одинакова в любом положении. Без неё звук проваливается посередине.

**HRTF** — моделирование того, как звук огибает голову; позволяет отличить
«спереди» от «сзади». Есть в OpenAL, здесь нет намеренно.

## Системное

**Xlib** — библиотека для работы с X11, оконной системой Unix.

**X-сервер** — процесс, владеющий экраном и устройствами ввода. Программа
подключается к нему как клиент, даже локально.

**Keysym** — символ клавиши с учётом раскладки. **Keycode** — физический
номер клавиши.

**GLX** — прослойка между OpenGL и X11: создание контекста, обмен буферами.

**Контекст OpenGL** — всё состояние рисования. Пока он не сделан текущим,
вызовы `gl*` работать не будут.

**dlopen / dlsym** — открыть библиотеку во время работы программы и найти в
ней функцию по имени. Так подключены OpenGL и ALSA.

**ALSA** — звуковая подсистема Linux.

**Монотонные часы** — время, которое только идёт вперёд и не прыгает при
переводе системных часов.

## Архитектурное

**Хук (hook)** — указатель на функцию, которую позовёт библиотека. Способ
дать движку кусок игры.

**Инверсия управления** — не ты зовёшь библиотеку, а библиотека зовёт тебя.

**Немедленный интерфейс (immediate mode)** — интерфейс без объектов-виджетов,
описываемый заново каждый кадр.

**Удерживаемый интерфейс (retained mode)** — противоположность: дерево
объектов, живущее между кадрами.

**Фиксированный шаг** — логика считается всегда с одинаковым `dt`
независимо от частоты кадров.

**Спираль смерти** — состояние, когда догон отставания занимает больше
времени, чем прошло, и игра уже не выберется. Лечится ограничением числа
шагов за кадр.

**Freestanding** — режим компиляции без стандартной библиотеки. `buf/`
собирается так, что подтверждается `make freestanding`.

**Монолитный движок** — движок без разделения на «движок» и «ресурсы»:
игра компилируется вместе с ним в один бинарник.
